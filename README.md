## 🧠 这套系统能干什么

- **防失忆**：AI 干活前先查地图，直接继承全部上下文，不用从头复述
- **省 token**：先看 132 个节点的目录，再按需打开文件，不全量喂给 AI
- **可导航**：四层面包屑定位，最后一层直接给出文件在本机的真实路径
- **能纠错**：图谱可视化能逐层点开检查，断链、过期路径肉眼可见
- **经验复用**：每完成一件事沉淀一个节点，方法论越滚越大
