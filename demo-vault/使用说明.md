# 🎁 示例库：1:1 体验同款知识地图

> 这是一个**可以直接用 Obsidian 打开的迷你仓库**，让你 3 分钟体验"知识地图"的画面效果。

## 怎么打开（3 步）

1. **安装 Obsidian**（免费）：官网 https://obsidian.md 下载，一路下一步
2. **下载本文件夹**：点右上角 Code → Download ZIP，解压后找到 `demo-vault` 文件夹
3. **打开仓库**：Obsidian 启动页 → 「打开本地仓库文件夹」→ 选中 `demo-vault`

## 打开后你会看到

- 左侧文件列表：`00-总览` → `分类` → `项目` → `知识点` → 源文件登记，**四层结构**
- 按 `Ctrl+G` 打开**关系图谱**：节点之间连成网络，绿点=知识点、橙点=项目、青点=分类
- 主题色已预置为绿色系（和作者的公众号「听风声」同款配色）
