# SelfLock自律锁

> 第 2 层 · 项目 ｜ 所属：[[项目实战]]

## 一句话

用手势画三角形触发锁屏的 Android 自律 App，锁屏后必须看完一段视频才解锁。

## 问题

想刷手机时缺少「强制中断」，靠自控力没用。

## 判断

把「想停下」变成一个动作仪式：画魔法阵 → 立刻锁屏 → 播放视频 → 播到一半自动解锁。关键是增加摩擦，而不是彻底禁止。

## 动手

用无障碍服务监听手势轨迹，匹配三角形后拉起锁屏；内嵌播放器播放指定视频；用 GitHub Actions 云端编译出 APK 装真机。

## 验证

真机可触发锁屏与解锁；云端编译成功产出 APK；覆盖安装需要递增版本号。

## 沉淀

权限类 App 的坑全在系统层：无障碍被回收、未知来源被拦、后台被清理——功能本身反而最简单。
