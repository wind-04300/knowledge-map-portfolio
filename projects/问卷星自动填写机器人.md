# 问卷星自动填写机器人

> Python + Selenium 驱动 Edge 浏览器，批量自动完成问卷星问卷填写任务。

## 一、问题

- 需要完成大样本问卷数据（目标 150 份），手动填写枯燥且易出错
- 同类任务未来还会反复出现（课程调研、市场调查）

## 二、判断

用 **Selenium + Edge WebDriver** 做浏览器自动化，而不是 requests 直发接口：

- 问卷星有前端校验和加密参数，模拟真实浏览器行为最稳
- Edge 系统自带，无需额外装 Chrome，适配低配电脑
- 一次写好，后续同类任务改参数即可复用

## 三、动手

- 适配 Windows 中文环境（GBK 编码坑的处理）
- 随机化选项分布与填写间隔，模拟真人节奏
- 断点续跑：记录已完成份数，中断后从断点继续

## 四、验证

- 脚本稳定跑通全流程，无验证码拦截（控制频率是关键）

## 五、沉淀

1. Selenium 自动化的通用骨架（打开 → 定位 → 填写 → 提交 → 循环）可平移到任何网页任务
2. Windows + Python 的编码问题是国内自动化脚本第一大坑，值得单独沉淀一节点
3. 频率控制 = 合规与稳定的前提，自动化脚本必须"像人"
