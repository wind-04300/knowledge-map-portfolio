# 📦 项目成果卡

这个文件夹里每一篇笔记 = 一个真实项目的"成果卡"。统一用下面的模板，保持"做了什么/怎么解决/学到什么"三段式，**不写个人隐私**。

## 成果卡模板（复制即用）

```markdown
# 项目名：一句话定位

![项目封面或截图](../assets/图片.png)

## 一、问题
（当时遇到了什么麻烦？为什么值得做？）

## 二、判断
（我选了什么方案？为什么是它而不是别的？）

## 三、动手
（关键技术栈 + 最有代表性的 1~2 个实现要点）

## 四、验证
（结果如何？用什么数据/场景证明它真的好用？）

## 五、沉淀
（学到了什么可以复用到下一个项目？）

---
状态：🚧 进行中 / ✅ 已完成　|　技术栈：xxx、xxx　|　周期：xxxx-xx ~ xxxx-xx
```
